🫧 Burbujas

Apunta con el dedo y suelta para disparar. Junta 3 o más del mismo color para reventarlas. Toca la burbuja de abajo a la izquierda para cambiarla.
Si revientas muchas de un tiro, haces caer varias o encadenas 3 tiros seguidos, ganas una bomba 💣, un arcoíris 🌈 o un rayo ⚡.
